# NEUROVA — Premium Medical AI Website

## محتوى الحزمة

هذا موقع تعريفي وتسويقي متكامل لمشروع **Neurova**، مستقل عن منصة تحليل الصور الطبية الموجودة على:

https://www.visioncode-studio.com/neurova/landing

النسخة جاهزة للنشر كموقع ثابت (Static Website) على GitHub Pages أو Netlify أو أي استضافة تدعم HTML / CSS / JavaScript.

### الملفات المطلوبة في المستودع

```text
neurova-website/
├── index.html
├── styles.css
├── app.js
├── manifest.webmanifest
├── README_AR.md
└── assets/
    ├── neurova-symbol.png
    ├── neurova-original.webp
    ├── brain-synthetic.webp
    ├── retina-synthetic.webp
    ├── label-projet-innovant.webp
    ├── label-stamp.webp
    ├── icon-192.png
    └── icon-512.png
```

> **مهم:** لا ترفع ملفات مجلد `assets` بجانب `index.html`، بل داخل مجلد باسم `assets` تمامًا، حتى تعمل المسارات.

## النشر على GitHub Pages

1. افتح مستودعًا جديدًا على GitHub (مثال: `neurova-website`).
2. ارفع ملفات الموقع إلى **جذر المستودع**. عبر واجهة GitHub يمكن فتح **Add file → Upload files** وسحب جميع الملفات مع مجلد `assets`. يمكن أيضًا إنشاء المجلد أولًا ثم رفع محتوياته.
3. تأكد من أن `index.html` في المستوى الرئيسي، وليس في مجلد إضافي.
4. اذهب إلى `Settings → Pages → Build and deployment`.
5. اختر `Deploy from a branch`، ثم `main`، ثم `/ (root)` واضغط `Save`.
6. بعد نشر الصفحة افتح رابط GitHub Pages، وجرّب جميع الروابط واللغات على الهاتف.

> إذا كان لديك مشروع على GitHub بالفعل، يمكنك استبدال ملفات الموقع القديمة بهذه الملفات. **لا تستبدل مشروع منصة التحليل الطبي الحالية** ما لم تكن تريد ذلك عمدًا، لأن هذا الموقع تعريفي وليس منصة تحليل فعلية.

## العناصر المتوفرة

- هوية بصرية رسمية مبنية على شعار Neurova المرسل.
- واجهة استعراضية تفاعلية توضيحية للرنين المغناطيسي وقاع العين.
- العربية والفرنسية والإنجليزية مع تغيير اتجاه الكتابة آليًا.
- روابط منصة Neurova الحالية وInstagram وFacebook وTikTok.
- نموذج تواصل يفتح تطبيق البريد لتجهيز الرسالة إلى `contact.neurova.dz@gmail.com`؛ لا توجد قاعدة بيانات أو خدمة خادم وراء النموذج.
- قسم مشروع مبتكر مع نسخة من الصورة التي أرسلها فريق Neurova.
- تصميم متجاوب للهاتف واللوحي والحاسوب، دون مكتبات JavaScript أو خطوط خارجية إلزامية.

## معلومات طبية مهمة

**الصور المستخدمة `brain-synthetic.webp` و`retina-synthetic.webp` صور تم إنشاؤها برمجيًا للعرض فقط، وليست صور مرضى ولا نتائج نموذج Neurova.** ليس هناك تحليل طبي يجري عند الضغط على أزرار المعاينة. يجب ألا يُستخدم الموقع كأداة تشخيص.

وصف المنصة ومجالات العمل مستمد من المعلومات التي قدمها صاحب المشروع وصفحة المنصة الحالية. لا يدعي الموقع وجود اعتماد تنظيمي أو تحقق سريري أو نتائج حساسية/دقة غير موثقة.

## تعديلات سريعة

- معلومات التواصل: ابحث عن `contact.neurova.dz@gmail.com` في `index.html` و`app.js`.
- روابط مواقع التواصل: موجودة ضمن `index.html`.
- النصوص وترجماتها: الفرنسية في `index.html` والإنجليزية والعربية في `app.js`.
- الألوان والشكل: ملف `styles.css`.
- الصور والشعار: مجلد `assets`.

## لماذا لا يحتوي على صفحة تسجيل حقيقية؟

الصفحة التعريفية توجه الزائر إلى المنصة الموجودة فعليًا عبر زر **Plateforme**، دون اختلاق نظام حسابات أو استضافة بيانات مرضى على موقع ثابت.
